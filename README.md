# ARのぼり旗カメラ (AR BANNER FLAG CAMERA)

オリジナルのぼり旗の画像を用意するだけで、Webブラウザ（WebAR）を通して現実空間に3Dのぼり旗をリアルタイムにシミュレーション・配置・撮影できるカメラWebアプリケーションです。  
風シミュレーションによる布の揺れや影、環境光（色温度・光源の向き）を自在に調整し、イベント・店舗・同人即売会などの宣伝・設置イメージを実空間で手軽に確認・撮影できます。

- **Webアプリ**: [https://nyaftama.github.io/ar-banner-flag/](https://nyaftama.github.io/ar-banner-flag/)
- **作者**: [@nyaftama](https://nyaftama.github.io/)

## 主な機能

1. **WebARカメラ ＆ ジャイロセンサー連動**
   - スマートフォンの背面カメラ映像とジャイロセンサーによる、互換性を重視したスムーズな空間追従
   - 撮影倍率切り替え（1x / 2x / 3x ズーム、全環境対応）
   - カメラのフラッシュ（トーチ）発光切り替え（対応端末）
   - 現在の端末の向きを基準正面に再キャリブレーションできる「視点基準リセット」機能

2. **リアルタイム風シミュレーション ＆ 流線可視化**
   - GPUバーテックスシェーダーによる、風の強さや周期的なうねりを伴う布地のリアルな揺れ表現
   - 「風の向き」（360°角度調整）と「風の強さ」（0〜100%）の無段階調整
   - 風向き・強さの調整中に空間を流れる3Dパーティクル流線エフェクトによる風向アシスト表示

3. **自由な旗配置 ＆ タッチ・マウス操作**
   - のぼり旗を最大3セットまで実空間に同時配置可能
   - 1本指スワイプおよびPCマウスドラッグによる直感的な床面（XZ平面）移動
   - 2本指ピンチ操作およびマウスホイールによる無段階の拡大縮小（30%〜300%）
   - マルチタッチ非対応端末やPC向けに、選択中の旗サイズを調整できるボタン群を常時配置
   - 移動・拡縮操作中の現在座標・サイズ情報の画面下部リアルタイム表示
   - サムネイル一覧からのスムーズな旗切り替え機能
   - 現在の旗の向き・反転・透明度・カラー設定をワンタップで別の旗に複製・適用できる「同じ設定を適用＆選択」機能

4. **充実のカスタマイズ ＆ 環境設定**
   - **旗の個別設定**: 向き（360°回転）、反転（水平・垂直）、透明度（10〜100%）、ポールの色、スタンドの色
   - **環境・ライティング設定**: 光の向き（方位角）、光の強さ、光源色（暖色〜自然光〜寒色）、影の濃さ
   - 環境・ライティング設定のLocalStorage自動保存・復元、および「リセット」機能

5. **写真撮影 ＆ ギャラリー管理 ＆ シェア**
   - カメラ映像と3Dのぼり旗・影を合成した写真撮影
   - 撮影中スピナー演出と誤操作防止のクールダウン機構
   - アプリ内フォトギャラリー（最大10枚一時保存、サムネイル一覧、フルサイズプレビュー、端末ダウンロード、写真削除）
   - ダウンロード制限環境（アプリ内ブラウザ等）向けの長押し保存案内＆共有フォールバック
   - 撮影した写真のX（旧Twitter）へのシェア投稿機能
   - 写真が残っている場合のトップページ離脱確認モーダル

6. **互換性サポート ＆ アプリ内ブラウザ検知**
   - LINEやX（Twitter）等のアプリ内ブラウザーを自動検出し、トースト通知およびスタート画面の注意書きで標準ブラウザ利用を案内
   - 各種環境に応じた安全な機能フォールバック（ハードウェアズーム非対応時のCSS拡大、ジャイロ無効時のカメラ単体動作など）

## 使い方

1. **画像を準備する**
   - のぼり旗にしたい画像（一般的な縦長比率 1:3 等を推奨、アスペクト比は自動判定）を端末に用意します。

2. **ARカメラを起動する**
   - トップページの「ARカメラを起動」をタップし、カメラおよびモーションセンサー（ジャイロ）へのアクセスを許可します。

3. **のぼり旗を配置する**
   - 画面下の「旗を追加」ボタンから画像を選択すると、カメラ正面の空間にのぼり旗が立ち上がります（最大3本まで追加可能）。
   - 画面上の旗を1本指（またはPCのマウスドラッグ）で移動、2本指ピンチ（またはマウスホイール、サイズ変更ボタン）で大きさを調整できます。

4. **見た目や環境を調整する**
   - 下部バーの「環境・調整メニュー」を展開し、風の向き・強さ、光の向き・色、影の濃さ、旗の回転角度などを自由に調整します。

5. **写真を撮影・保存・シェアする**
   - シャッターボタンをタップして撮影します。撮影した写真は左下の「写真一覧」からプレビュー、端末へのダウンロード、X（旧Twitter）へのシェアが可能です（保存できない環境では画像を長押しして保存可能）。
